# Data-Engineering-Portfolio
This repository contains my personal portfolio in my journey to become a Data Engineer. 

## 📌 Description and projects

- We start with basic pratice with Python and SQL where we perform queries through Azure SQL to make an analysis using Claude API's 

## 🏋️‍♂️ Challenges and Practice

The Practice files contain exercises focused on core data structures and functions fundamental to Data Engineering:

- SQL: Aggregations, advanced filtering, and complex joins.
- Python: Algorithmic manipulation of arrays, strings, and dictionaries.

Conversely, the Grand Challenges transition into advanced data modeling, tackling the structural design of Fact and Dimension tables alongside production-level SQL implementation.

**Note**: Due to environment-specific limitations in Snowflake, Common Table Expressions (CTEs) are utilized inline to mock and represent Dimension tables rather than instantiating them as physical DDL schemas.

## 🚀 Getting started, requirements before starting

- Install a Python version above 13.3.0, and the following libraries: Numpy, Anthropic, Pandas, Matplotlib, Requests, Sqlalchemy

- It's necessary to create a key in Claude Console, **Don't push your key**

- **Snowflake** and **AWS** account to perform a complete data pipeline
